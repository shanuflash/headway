# Writing the app's text

Headway is a transit app for anyone riding Chennai Metro. Its text should read like a product, not a note to one rider. These rules follow Apple's [Writing guidelines](https://developer.apple.com/design/human-interface-guidelines/writing) (clarity first, then brevity) and Material's [writing guidance](https://m1.material.io/style/writing.html) (sentence case, concise, scannable). The transit terms match what Google Maps, Citymapper and CMRL's own signage use.

## Rules

- **Short as it can be.** Cut a sentence if the screen works without it. Don't explain how the app works ("planned on your line delays", "stays on this phone").
- **No chat.** Write labels, not conversation: no "you'll", "I'll", "Took a bus?", "Running early or late?" or jokes. Headings are nouns, and buttons are verbs, ideally a verb and a noun: "Add route", "Start trip".
- **Sentence case** everywhere: "Departures from", not "Departures From".
- **Numerals and short units.** "3 min", "8:14 AM", "Platform 2", "±2 min".
- **Front-load what matters.** "Leaves in 3 min", not "The 8:14 AM train from Guindy leaves in 3 min".
- **The same word for the same thing**, everywhere (see below).

## Terms

| Use | Not |
| --- | --- |
| Next train, Later train, Last train | Next one, the train you're catching |
| Leaves 8:14 AM, Leaves in 3 min | Departs, goes at |
| Arrives 8:40 AM, Arrive at Koyambedu | Gets in, you'll reach |
| Towards Airport | Toward, to, heading to |
| Change at Alandur | Transfer, switch trains, interchange |
| Get off at, Board at | Alight, hop on |
| Platform 2 | Pf 2, track |
| Front coach, Middle coach, Rear coach | Car, carriage, back |
| Delay, 2 min late, 2 min early, On time | Running behind, shift |
| Scheduled, Expected | Timetabled, you'll see |
| Start trip, End trip | Follow this trip, track it |
| Countdown | Reminder, alarm |
| Route (a saved pair of stations) | Trip, journey (a trip is one ride, with its changes) |
| Departures from | Next trains at |
| Settings, Lines, Map, Routes | |

Line names: Blue Line, Green Line, Yellow Line, and Inter-corridor for the Airport and Central service via CMBT.
